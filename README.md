# 美容皮膚科まとめサイト（試作版）

美容皮膚科の機器・製剤・疾患・合併症を、国内の承認状況と出典つきで整理したサイトの公開用ファイルです。

- `index.html` … サイト本体（1ファイルで動きます）。検索エンジンに載らない設定（noindex）を入れています。
- `sources.json` … 新着に使う媒体のフィード一覧。
- `scripts/update_feed.py` … フィードを取り直して `index.html` の新着を差し替えるスクリプト。
- `.github/workflows/update-feed.yml` … 上のスクリプトを毎日 06:17（日本時間）に実行します。Actions の画面から手動でも実行できます。

内容は AI が公開情報を調べてまとめたもので、医師による確認前です。診療上の判断には一次資料を確認してください。
製品写真は各メーカー・販売元のサイトから直接読み込んでおり、このリポジトリには含めていません。
